# Installation / Updating / Removal leads the category sample, involved entities include Python 3.11, Openshot, Kwin etc - while Loading / Startup leads the entity sample (AppImage), involved entities include Terminal, PCSX2, OpenShot 3.0, etc


The category sample takes ten topics from the Manjaro Linux third-party forum and the entity sample (AppImage) takes ten topics from the same forum, but using a specific entity search filter. So, which problem states are the most frequent and which entities are associated with them? The installation / updating / removal problem state is the most frequent regarding the category sample, and it includes the following entities: python 3.11, Openshot, Kwin, Davinci Resolve, Manjaro Linux, Windows 10, and dd. The loading / startup problem state is the most frequent within the entity sample (AppImage). It includes the entities PCSX2, Openshot 3.0, VSCodium, libwebkit2gtk-4.0.so.37, terminal, and libgio.
